kapylauncher for Linux — @version@

1. Распакуйте архив в папку, доступную для записи.
2. Запустите kapylauncher.sh (или откройте его через терминал).
3. При первом запуске лаунчер скачает Eclipse Temurin Java 21 и проверит SHA-256.

Поддерживаются Linux x86_64 и ARM64. Для загрузки Java нужны curl, tar и sha256sum.
Игровые файлы будут храниться в ~/.local/share/kapylauncher/game.

Обновления лаунчера проверяются автоматически при каждом запуске. Для установки обновления
проект публикует новый launcher.jar в GitHub Releases; игровые версии и модлоадеры загружаются
самим лаунчером.
